
# Unit 3: Linked Lists

## Data Structures Lab Assignment

This folder contains C++ programs based on Unit 3: Linked Lists.

## Programs Included

### 1. Singly Linked List
- Insertion at a given position
- Deletion at a given position
- Reversing the linked list
- Concatenation of two linked lists
- Displaying the linked list

### 2. Doubly Linked List
- Insertion at a given position
- Deletion at a given position
- Reversing the linked list
- Concatenation of two linked lists
- Displaying the linked list

### 3. Circular Linked List
- Insertion at a given position
- Deletion at a given position
- Reversing the linked list
- Concatenation of two circular linked lists
- Displaying the linked list


## Technologies Used
- Programming Language: C++
- Concepts: Structures, Pointers, Dynamic Memory Allocation,
  Singly Linked Lists, Doubly Linked Lists and Circular Linked Lists.

## How to Compile

Compile any program using a C++ compiler:

```bash
g++ filename.cpp -o output
```

Run on Windows:

```bash
output.exe
```

## Learning Outcomes
- Understanding linked list structures.
- Performing insertion and deletion operations.
- Understanding pointer manipulation.
- Implementing real-world applications using linked lists.
