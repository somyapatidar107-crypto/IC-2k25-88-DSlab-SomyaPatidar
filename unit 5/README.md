
# Unit 5: Queues

## Data Structures Lab Assignment

This folder contains C++ programs based on Queue data structures.

## Programs Included

1. Static Queue using Array
2. Dynamic Queue using Linked List
3. Circular Queue
4. Double Ended Queue (Deque)
5. Array-Based Priority Queue

## Concepts Used

- FIFO (First In First Out)
- Enqueue and Dequeue
- Front and Rear
- Static Queue
- Dynamic Queue
- Circular Queue
- Deque
- Priority Queue
- Min Heap
- Process Scheduling

## Technology Used

- Programming Language: C++
- Data Structures: Queue and Priority Queue

## Compilation

```bash
g++ filename.cpp -o output
```

On Windows, run:

```bash
output.exe
```

## Learning Outcomes

- Understand the FIFO principle.
- Implement static and dynamic queues.
- Understand circular queue operations.
- Implement insertion and deletion at both ends.
- Understand priority-based processing.
- Apply queues to real-world applications.
