
# Unit 4: Stacks

## Data Structures Lab Assignment

This folder contains C++ programs based on Stack data structures.

## Programs Included

1. Static and Dynamic Stack Implementation
2. Infix to Postfix and Prefix Conversion
3. Postfix Expression Evaluation
4. Expression Evaluator with Parentheses and Operator Precedence
5. Undo/Redo Application Using Stacks

## Concepts Used

- Stack
- LIFO (Last In First Out)
- Array Implementation
- Linked List Implementation
- Push and Pop Operations
- Operator Precedence
- Expression Conversion
- Expression Evaluation
- Undo and Redo Operations

## Technology Used

- Programming Language: C++
- Data Structure: Stack

## Compilation

```bash
g++ filename.cpp -o output
```

On Windows, run:

```bash
output.exe
```

## Learning Outcomes

- Understand the LIFO principle.
- Implement static and dynamic stacks.
- Convert and evaluate expressions.
- Understand operator precedence and parentheses.
- Implement Undo and Redo using stacks.
