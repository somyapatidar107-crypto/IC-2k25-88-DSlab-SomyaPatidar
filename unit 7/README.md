
# Unit 7: Graphs

## Data Structures Lab Assignment

This folder contains C++ programs based on Graph data structures.

## Programs Included

1. Graph Representation using Adjacency Matrix and Adjacency List
2. BFS and DFS Traversals (Recursive and Iterative)
3. Weighted Graph and Dijkstra's Shortest Path Algorithm
4. Social Network / Friendship Graph
5. Network Connectivity Analyzer

## Concepts Used

- Graphs
- Vertices and Edges
- Directed and Undirected Graphs
- Adjacency Matrix
- Adjacency List
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Weighted Graphs
- Dijkstra's Algorithm
- Connected Components
- Topological Sorting

## Technology Used

- Programming Language: C++
- Data Structures: Graph, Queue, Stack and Priority Queue

## Compilation

```bash
g++ filename.cpp -o output
```

On Windows, run:

```bash
output.exe
```

## Learning Outcomes

- Understand graph representations.
- Implement BFS and DFS.
- Find shortest paths using Dijkstra's algorithm.
- Apply graphs to social networks and maze solving.
- Understand topological sorting.
- Analyze network connectivity.
