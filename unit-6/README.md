
# Unit 6: Trees

## Data Structures Lab Assignment

This folder contains C++ programs based on Tree data structures.

## Programs Included

1. Binary Tree Traversals (Recursive and Iterative)
2. Binary Search Tree (Insert, Delete, Search, Min, Max and Validation)
3. AVL Tree Implementation with Rotations and Balancing
4. Threaded Binary Tree
5. File System Simulator using a Tree
6. Expression Tree from Postfix Expression
7. Symbol Table using Binary Search Tree
8. Directory Autocomplete using Trie

## Concepts Used

- Binary Trees
- Tree Traversals
- Binary Search Trees
- AVL Trees
- Expression Trees


## Technology Used

- Programming Language: C++
- Data Structures: Binary Tree, BST, AVL Tree and Trie

## Compilation

```bash
g++ filename.cpp -o output
```

On Windows, run:

```bash
output.exe
```

## Learning Outcomes

- Understand tree structures and their applications.
- Perform recursive and iterative tree traversals.
- Implement BST operations.
- Understand AVL rotations and balancing.
- Use trees in expression evaluation and file systems.
- Understand symbol tables and Trie-based prefix searching.
